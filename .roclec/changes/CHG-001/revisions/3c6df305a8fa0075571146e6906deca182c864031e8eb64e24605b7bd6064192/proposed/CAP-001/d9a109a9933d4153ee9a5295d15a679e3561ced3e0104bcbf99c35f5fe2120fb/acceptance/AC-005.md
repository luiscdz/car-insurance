# AC-005: Field presentation by configured type

Requirement: REQ-002.

Given a published field configured in Strapi
When its form step is shown
Then the field shows its configured label above the control, a `*` marker when it is required, and its configured help text below it when one is configured
And its control matches its type: text gives a text input, number a numeric input, select a list of options (AC-006), date a date input, checkbox a checkbox whose text is the label.

**Verification:** Unit test (component) of every field type, required and optional, with and without help text, with fixtures for both countries.
