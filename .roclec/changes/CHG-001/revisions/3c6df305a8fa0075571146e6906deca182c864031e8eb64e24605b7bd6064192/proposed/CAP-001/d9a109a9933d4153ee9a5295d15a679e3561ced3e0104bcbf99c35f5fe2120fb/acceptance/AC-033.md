# AC-033: Browser leave confirmation on reload or tab close

Requirement: REQ-005.

Given the current step has unconfirmed values: at least one field whose value differs from the value stored for that step, or from empty when the step was never completed
When the person reloads the page or closes the tab or the window
Then the browser's own leave confirmation is shown, with the text the browser sets (it cannot be customized and does not come from Strapi)
When the person chooses to stay
Then the page, the step and the typed values remain unchanged
When the person chooses to leave
Then the page unloads and the unconfirmed values are lost (AC-022).

Given the current step has no unconfirmed values (nothing typed, or only values equal to the stored ones)
Then reloading or closing shows no confirmation.

The browser shows the same confirmation for any other way of unloading the page, such as typing another address or following a link to another site, because it does not tell these apart from a reload. Browsers that do not support this confirmation, notably Safari on iOS, show none and the unconfirmed values are lost.

**Verification:** End-to-end test in a browser that supports the confirmation, for Colombia and Chile (reload and close with and without unconfirmed values; stay and leave), and unit test of the unconfirmed-values detection.
