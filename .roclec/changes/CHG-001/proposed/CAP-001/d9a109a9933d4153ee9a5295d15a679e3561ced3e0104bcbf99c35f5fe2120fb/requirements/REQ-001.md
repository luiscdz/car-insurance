# REQ-001: Country context

The application serves the quoting wizard in the context of one country, identified by the first segment of the address (`/co`, `/cl`), as decided in ADR-001. The root address lets the person choose among the countries published in Strapi. An address whose country is unknown or not published shows a controlled message instead of a wizard. The theme configured in Strapi for the country is applied, with the default theme as fallback. No behavior depends on code that names a specific country (P1).

Acceptance: AC-001, AC-002, AC-003.
