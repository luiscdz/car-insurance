# REQ-002: Form steps built from content

Each form step of the country's wizard is built from its published configuration in Strapi: step title, fields and, for each field, label, type (text, number, select, date, checkbox), required flag, validations, help text, error message, order and, for select fields, options. The wizard's own copy also comes from Strapi. A change published in Strapi is visible on the next load of the application without a code change or a deployment (P2).

Acceptance: AC-004, AC-005, AC-006, AC-007, AC-008.
