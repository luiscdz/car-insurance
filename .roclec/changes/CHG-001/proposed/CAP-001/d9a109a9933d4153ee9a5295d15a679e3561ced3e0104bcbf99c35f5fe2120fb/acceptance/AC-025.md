# AC-025: Stored data reconciled with the current configuration

Requirement: REQ-005.

Given the tab holds data stored for the country
When the wizard loads a configuration that changed since the data was stored
Then stored values of fields that are no longer published are discarded
And a step whose stored values no longer satisfy the current configuration (a new required field, a changed validation) is treated as not complete: it shows the stored values that still apply, AC-024 applies to later steps, and its errors appear as stated in AC-010 and AC-011.

**Verification:** Unit test of the wizard data store with fixtures for both countries.
