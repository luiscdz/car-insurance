# AC-020: Data kept when going back

Requirement: REQ-005.

Given the person completed a form step and moved to a later step
When they go back with the wizard's back action or the browser's back button
Then the previous form step shows every value they entered, including chosen select options and checkbox states, with no error displayed.

The first step of the wizard offers no back action.

**Verification:** End-to-end test for Chile (form step 2 back to form step 1, with both back mechanisms) and unit test of the wizard data store with fixtures for both countries.
