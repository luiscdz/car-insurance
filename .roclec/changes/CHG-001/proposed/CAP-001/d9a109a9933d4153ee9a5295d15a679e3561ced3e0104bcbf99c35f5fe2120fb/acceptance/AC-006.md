# AC-006: Select options from Strapi

Requirement: REQ-002.

Given a select field with options configured in Strapi
When the person opens the list
Then it offers exactly the options configured for that field, each with its configured label, in their configured order
And no option is chosen until the person chooses one.

Example with the seed: the Colombian document type offers "Cédula de ciudadanía" and "Cédula de extranjería"; the make field of each country offers that country's makes.

**Verification:** Unit test (component) and end-to-end test (Colombian document type and the makes of both countries).
