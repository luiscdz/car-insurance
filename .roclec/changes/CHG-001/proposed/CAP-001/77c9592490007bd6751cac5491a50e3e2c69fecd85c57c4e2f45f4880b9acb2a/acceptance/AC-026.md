# AC-026: Entered data stays in the browser

Requirement: REQ-005.

Given the person enters values in a form step
When they fill it in, advance or go back
Then the values never appear in the address, in any request sent to Strapi or in the browser console
And they are kept only in the browser's session storage of that tab.

**Verification:** End-to-end test observing the address, the requests and the console, for Colombia and Chile.
