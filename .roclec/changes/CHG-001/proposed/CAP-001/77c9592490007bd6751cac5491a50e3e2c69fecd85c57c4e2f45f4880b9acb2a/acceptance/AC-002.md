# AC-002: Unknown or unpublished country code

Requirement: REQ-001.

Given the first segment of the address does not exactly match the code of a country published in Strapi (for example `/xx`, `/CO`, or a country saved only as a draft)
When the person opens that address or any address below it
Then they see a fallback message in Spanish stating that the country is not available, announced to assistive technologies, with a link to the country selection at the root address
And no wizard step, field or content of another country is shown.

**Verification:** End-to-end test (`/xx`) and unit test (upper-case code; country absent from the published response).
