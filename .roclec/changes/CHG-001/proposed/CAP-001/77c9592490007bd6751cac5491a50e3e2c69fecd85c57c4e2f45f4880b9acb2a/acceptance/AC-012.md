# AC-012: Supported validations and inclusive limits

Requirement: REQ-003.

Given a field configured in Strapi with any of the following validations
When the person enters a value
Then the field is valid only if the value satisfies all of them, every limit being inclusive:

- required: a value is present; text made only of spaces, an unchecked checkbox and a select with no option chosen count as empty;
- text: minimum length, maximum length and a pattern that the whole value must match, evaluated on the value without leading or trailing spaces;
- number: minimum value, maximum value and, when configured, whole numbers only;
- date: minimum age in whole years at the current date (AC-014);
- year: a range relative to the current year (AC-013).

A field that is not required and is left empty is valid, and its other validations are not evaluated.

**Verification:** Unit test of each validation at, below and above its limits, with fixtures for both countries.
