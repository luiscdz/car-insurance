# AC-092: Responsive summary and target size

Requirement: REQ-019.

Given widths of 320, 375 and 1280 CSS pixels
When the summary, the terms dialog, the payment error and the confirmation are shown for each country
Then all content is visible without horizontal scrolling, and long labels, values, plan names and quote numbers wrap
And the terms text scrolls inside the dialog with its title and close action visible
And every interactive target is at least 24 × 24 CSS pixels.

**Verification:** End-to-end test (no horizontal overflow at 320 and 375 px; target sizes) for both countries; declared manual check at 375 and 1280 px.
