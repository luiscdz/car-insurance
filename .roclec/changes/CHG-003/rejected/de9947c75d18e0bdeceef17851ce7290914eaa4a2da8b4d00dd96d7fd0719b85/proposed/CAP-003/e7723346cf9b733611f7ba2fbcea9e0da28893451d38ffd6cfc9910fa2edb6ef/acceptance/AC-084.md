# AC-084: Simulated quote number

Requirement: REQ-017.

Given the endpoint approves a payment for country code c
Then the quote number is c in upper case, a hyphen, the endpoint's current date in UTC as YYYYMMDD, a hyphen, and six characters drawn at random from the upper-case letters A to Z and the digits 0 to 9 (for example `CO-20261123-7KQ2MX` and `CL-20261123-A9F03Z`)
And the endpoint does not store it; being random and stateless, two payments may in rare cases receive the same number, which is accepted for the simulation.

The country part comes from the request's country code; no code names a country.

**Verification:** Unit test of the quote number generation with a fixed clock and random source (format; upper-case prefix for both countries; UTC date just before and after midnight); end-to-end test checking the format for Colombia and Chile.
