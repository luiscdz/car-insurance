# AC-091: Keyboard-only use of the summary

Requirement: REQ-019.

Given the summary step of each country
Then the person can, with the keyboard only, in a logical tab order and with visible focus that is never hidden: reach every edit action and the change plan action, accept the terms, open, scroll and close the terms dialog, pay, pay again after an error, and start a new quote from the confirmation
And there is no keyboard trap other than the open terms dialog, which keeps focus inside until it closes (AC-075).

**Verification:** Declared manual check for Colombia and Chile, recorded as an observation.
