# AC-088: Direct entry to the summary step

Requirement: REQ-018.

Given every form step of the country is complete and a plan is chosen with its final price for the current data stored in this tab, and no confirmation is stored
When the person opens the summary step's address directly (typed, bookmarked or shared)
Then the summary is shown with the stored data, plan and final price, the terms unaccepted and no error displayed.

Given an earlier step is not complete, AC-024 and AC-056 apply: the person is taken to the first step that is not complete.
Given a confirmation is stored, AC-085 applies.

**Verification:** End-to-end test for one country (summary address in a tab with complete data; in a new tab); unit test of the step resolution.
