# AC-090: Accessible summary and automated accessibility scan

Requirement: REQ-019.

Given the summary step of each country: as first shown, with the message asking to accept the terms, with the terms dialog open, while a payment is processed, with the payment error, and the confirmation
Then each data section and the plan section is introduced by a heading, and each label and value pair is exposed as a term and its description
And each edit action's accessible name includes its section's title
And a masked value is exposed to assistive technologies exactly as shown (AC-069)
And the checkbox's programmatic label is the terms acceptance label, and the message asking to accept the terms is associated with it
And the disabled and busy states of the pay action are exposed
And the processing text, the payment error message, the message asking to accept the terms and the confirmation are announced as they appear
And the automated accessibility scan reports no WCAG 2.2 AA violation.

**Verification:** End-to-end test with the automated accessibility scan for Colombia and Chile in each state above; unit test (component) of the accessible names, associations and announcements.
