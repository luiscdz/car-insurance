# AC-069: Masked fields

Requirement: REQ-014.

Given the country's form fields in Strapi
Then a text field can be marked as masked in the summary
And a mark on a field of any other type makes the country's content invalid (AC-017).

Given a marked field has a stored value
When the summary is shown
Then its value is shown with every letter and digit replaced by the mask character `•`, except the last four letters or digits, which stay visible as entered
And every other character (dots, hyphens, spaces) is kept in its place as entered
And when the value has four letters and digits or fewer, all of them are replaced
And, for example: `1234567890` is shown as `••••••7890`; `123456` as `••3456`; `12.345.678-5` as `••.•••.678-5`; `12345678-k` as `•••••678-k`; `1234567-K` as `••••567-K`
And the complete value does not appear anywhere on the summary step or on the confirmation, including text exposed only to assistive technologies
And the stored value stays complete, so editing the step shows it in full (AC-071).

The rule is the same for every country, and the mark is configuration: no code names a field, a document type or a country to decide what is masked.

**Verification:** Unit test of the masking function (the examples above, values of four or fewer letters and digits, separators at the start and the end); unit test of the shared content schemas with a mark on a field that is not text; end-to-end test for Colombia (document number) and Chile (RUT) checking the masked text and that the complete value is absent from the page.
