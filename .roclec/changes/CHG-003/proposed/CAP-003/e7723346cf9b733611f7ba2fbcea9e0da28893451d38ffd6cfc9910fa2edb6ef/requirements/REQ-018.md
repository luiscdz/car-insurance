# REQ-018: Navigation and data of the summary step

The summary step follows the wizard's navigation: it is shown only when every earlier step is complete, it is shown again after a reload, and it never asks before leaving because it has no field values to confirm. The terms acceptance and an unanswered payment are not kept when the person reloads or leaves. Entered data stays in the browser (AC-026).

Acceptance: AC-088, AC-089.
