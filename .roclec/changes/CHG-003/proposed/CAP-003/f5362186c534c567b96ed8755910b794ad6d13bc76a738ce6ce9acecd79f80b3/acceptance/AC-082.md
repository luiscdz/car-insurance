# AC-082: Public access for terms and the payment

Requirement: REQ-016.

Given a fresh start of the project, or any later start
Then the public role of Strapi has exactly the read actions (`find`, `findOne`) of the content types the wizard reads, now including terms, plus the price-quote endpoint and the simulated payment endpoint, and nothing else
And the browser reads the terms and sends the payment request without any token (P4).

This is the only statement of the public role: it replaces AC-066 of CAP-002, which this change retires (owner answer Q15).

**Verification:** Unit test of the public role bootstrap (the exact list of public actions, applied idempotently); end-to-end test observing that the terms and payment requests carry no authorization header.
