# AC-068: Presentation of the stored values

Requirement: REQ-014.

Given a stored value of a field listed in the summary
Then a select field shows the label of the chosen option from Strapi, not its stored value (seed: "Cédula de ciudadanía", "Mazda")
And a date field shows the day, the month and the four-digit year with the browser's `Intl` date formatting for the country's locale, as the calendar date entered, never shifted by the device's time zone (seed: 5 March 1990 is shown as `05/03/1990` with es-CO and as `05-03-1990` with es-CL, as `Intl` produces them)
And a number field shows the number as entered, without thousands separators (seed: `2020`, never `2.020`)
And a text field shows the text as entered, including letter case (a plate entered as `abc123` is shown as `abc123`), unless it is masked (AC-069)
And a checkbox field shows the yes text or the no text of the summary copy (AC-073)
And a field that is not required and was left empty is not listed.

No formatting rule in code names a country or a locale.

**Verification:** Unit test of the value presentation for every field type with fixtures for both countries' locales, including a date checked with the device time zone set west and east of UTC.
