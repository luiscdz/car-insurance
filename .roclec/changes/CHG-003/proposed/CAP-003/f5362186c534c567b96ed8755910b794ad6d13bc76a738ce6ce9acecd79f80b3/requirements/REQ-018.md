# REQ-018: Navigation and data of the summary step

The summary step follows the wizard's navigation: it is shown only when every earlier step is complete and it is shown again after a reload. It asks before leaving only while a payment is being processed, with the leave confirmations of the wizard (AC-033, AC-034); otherwise it never asks, because it has no field values to confirm. The terms acceptance and an unanswered payment are not kept when the person reloads or leaves. Entered data stays in the browser (AC-026).

Acceptance: AC-088, AC-089, AC-096.
