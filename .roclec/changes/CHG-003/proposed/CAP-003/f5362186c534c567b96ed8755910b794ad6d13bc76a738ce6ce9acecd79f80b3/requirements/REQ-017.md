# REQ-017: Confirmation

An approved payment shows a confirmation with a simulated quote number, the plan and the amount paid, and no personal data. The confirmation is kept in the country's wizard data for the life of the browser tab, so the same quote is never paid twice; it is discarded when the person changes the quote or starts a new one.

Acceptance: AC-083, AC-084, AC-085, AC-086, AC-087.
