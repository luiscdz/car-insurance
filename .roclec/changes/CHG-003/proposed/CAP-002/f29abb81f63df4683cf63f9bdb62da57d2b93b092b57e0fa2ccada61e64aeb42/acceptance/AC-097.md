# AC-097: The final price is requested without a token

Requirement: REQ-009.

Given the person chose a plan on the plan step
When the browser requests its final price from the price-quote endpoint
Then the request carries no token and no authorization header, and the endpoint answers it as it answers the public role (P4)
And no other request of the plan step carries a token either.

This criterion keeps the price-quote part of the retired AC-066. The list of actions of the public role is stated only in AC-082 of CAP-003.

**Verification:** End-to-end test for one country observing that the plan and price-quote requests carry no authorization header.
