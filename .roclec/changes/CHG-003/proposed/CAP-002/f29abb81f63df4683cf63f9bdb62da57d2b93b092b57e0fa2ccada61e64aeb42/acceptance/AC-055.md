# AC-055: Stored choice reconciled with the current plans

Requirement: REQ-010.

Given the tab holds a chosen plan for the country
When the wizard loads plans among which that plan is no longer present (unpublished, deactivated, deleted or moved to another country in Strapi)
Then the choice and its final price are discarded, no plan is shown as chosen and no error is displayed
And the plan step is not complete, so AC-056 applies to the summary step.

**Verification:** Unit test of the wizard data store with fixtures for both countries.
