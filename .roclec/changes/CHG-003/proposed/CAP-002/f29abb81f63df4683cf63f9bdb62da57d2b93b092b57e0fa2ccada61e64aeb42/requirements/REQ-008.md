# REQ-008: Plan list built from content

The plan list step of the country's wizard shows the plans configured in Strapi for that country that are both published and active, in configured order. Each plan shows its name, short description, base price, coverages and benefits, and the plan marked as recommended is distinguished. The plan list copy comes from the country's content in Strapi. Plan content is validated before use (P3), and a change published in Strapi is visible on the next load of the application without a code change or a deployment (P2). No behavior depends on code that names a specific country (P1, ADR-001).

Acceptance: AC-036, AC-037, AC-038, AC-039, AC-040, AC-041.
