# REQ-010: Plan selection and navigation

The person chooses exactly one plan. The choice is stored in the country's wizard data when it is made, is kept per country for the life of the browser tab, survives going back, going forward and reloading, and is reconciled with the current plans. The person moves on to the summary step only with a chosen plan whose final price has been obtained for the current step 1 data. Confirming changed step 1 data keeps the choice and requires a new final price. Because the choice is stored when made, the plan step never has unconfirmed values and never asks before leaving.

Acceptance: AC-048, AC-049, AC-050, AC-051, AC-052, AC-053, AC-054, AC-055, AC-056, AC-057.
