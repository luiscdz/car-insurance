# REQ-012: Accessibility and responsive behavior of the plan list

The plan step meets the accessibility and responsive rules of the design reference (WCAG 2.2 AA; widths 320, 375 and 1280 CSS px; plan cards side by side on desktop and stacked on mobile; the recommended and the chosen plan are never conveyed by color alone) for the content of both countries (P6).

Acceptance: AC-060, AC-061, AC-062, AC-063.
