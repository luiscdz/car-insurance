# AC-042: Prices in the country's currency and format

Requirement: REQ-009.

Given a country whose entry in Strapi has currency code C and formatting locale L (seed: Colombia COP and es-CO; Chile CLP and es-CL)
When any price is shown on the plan step, base or final
Then it is formatted with the browser's `Intl` number formatting for locale L and currency C: the currency symbol that formatting gives for L, the thousands separator of L and no decimal digits
And with the seed, a base price of 1200000 is shown in Colombia as `$ 1.200.000` and a base price of 350000 in Chile as `$350.000`, with the spacing between symbol and number that `Intl` produces for each locale.

Prices are whole amounts of the currency; no decimal part is ever shown. No formatting rule in code names a country, a currency or a locale.

**Verification:** Unit test of the price formatting function with fixtures for both countries (compared with the output of `Intl` for the same locale and currency); end-to-end test checking one seeded base price in each country.
