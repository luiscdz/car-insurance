# AC-041: Plan content validation

Requirement: REQ-008.

Given the published, active plans received from Strapi for the country
Then each plan is valid only when it has:
- a name and a short description that are not blank;
- a base price that is a whole number greater than zero;
- a currency equal to the currency code of the country's entry;
- a whole-number order;
- at least one coverage, each with a name that is not blank and, optionally, a highlighted value that is not blank when present;
- zero or more benefits, each a text that is not blank;
- a recommended flag that is true or false, where an absent flag means false
When any received plan is not valid
Then the country's content is invalid and AC-017 applies: the fallback message is shown and no part of the wizard is shown.

Plans that are inactive or saved only as drafts are not received and therefore never make the content invalid.

**Verification:** Unit test of the shared content schemas with valid and invalid plan fixtures for both countries (each rule above broken once, including a base price of 0, a negative and a non-whole base price, and a currency that differs from the country's).
