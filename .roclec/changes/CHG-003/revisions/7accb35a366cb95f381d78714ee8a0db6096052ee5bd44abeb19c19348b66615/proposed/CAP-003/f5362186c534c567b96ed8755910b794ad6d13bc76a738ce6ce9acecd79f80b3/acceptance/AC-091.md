# AC-091: Keyboard-only use of the summary

Requirement: REQ-019.

Given the summary step of each country
Then the person can, with the keyboard only, in a logical tab order and with visible focus that is never hidden: reach every edit action and the change plan action, accept the terms, open, scroll and close the terms dialog, pay, answer the leave dialog of AC-096, pay again after an error, and start a new quote from the confirmation
And there is no keyboard trap other than the open terms dialog and the open leave dialog, which keep focus inside until they close (AC-075, AC-096).

**Verification:** Declared manual check for Colombia and Chile, recorded as an observation.
