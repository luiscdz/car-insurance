# REQ-019: Accessibility and responsive behavior of the summary

The summary step, the terms dialog and the confirmation meet the accessibility and responsive rules of the design reference (WCAG 2.2 AA; widths 320, 375 and 1280 CSS px; keyboard-only use; announced states; reduced motion) for the content of both countries (P6).

Acceptance: AC-090, AC-091, AC-092, AC-093.
