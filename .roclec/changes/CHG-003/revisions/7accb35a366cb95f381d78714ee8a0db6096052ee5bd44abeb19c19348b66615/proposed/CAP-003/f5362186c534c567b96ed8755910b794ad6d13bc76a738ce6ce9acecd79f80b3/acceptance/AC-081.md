# AC-081: Rejected or failed payment

Requirement: REQ-016.

Given the person activated pay with the terms accepted
When the payment request fails (network failure or HTTP error status), the endpoint answers that the payment is rejected, or the answer is not valid (it has no quote number in the format of AC-084)
Then the summary stays shown with the payment error message from Strapi next to the pay action, announced to assistive technologies, with no technical detail
And the entered data, the chosen plan, its final price and the terms acceptance are all kept, and the pay action is enabled again
When the person activates pay again
Then the error message is removed and exactly one new payment request is sent, with the locked state of AC-078
And if it is approved, the confirmation is shown (AC-083).

A rejection and a technical failure show the same message.

**Verification:** Unit test (component) of the error state and of paying again; end-to-end test for Colombia and Chile with the payment request answered as rejected from the browser, then allowed before paying again.
