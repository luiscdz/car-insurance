# AC-077: Terms loaded and validated with the country's content

Requirement: REQ-015.

Given the person opens any address of a country's wizard
Then the country's published terms are requested, filtered by the country, together with the country, its steps and its plans
And the loading state of AC-015 is shown until all of them have arrived
When the terms request fails (network failure or HTTP error status)
Then the unavailable state of AC-016 is shown, and its retry action requests all of them again, keeping the data already stored for the country in this tab
When the country has no published terms, more than one published terms entry, or terms whose text is empty or only blank
Then the invalid state of AC-017 is shown
And in none of these states is any step of the wizard shown.

**Verification:** Unit test of the shared content schemas (no terms, two entries, blank text) and of the content reader (filtered by country, published only); unit test (component) of the three states; end-to-end test with the terms request blocked from the browser.
