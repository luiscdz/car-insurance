# AC-085: Confirmation kept; the same quote is not paid twice

Requirement: REQ-017.

Given the confirmation of a quote is shown in the country's wizard in this tab
Then the confirmation (quote number, plan name and amount paid) is stored in the country's wizard data
When the person reloads the page, or returns to the summary step's address by any means (browser back or forward, the address typed, the plan step's continue) without having changed the quote (AC-086)
Then the same confirmation is shown, and the summary with its pay action is not shown, so the same quote cannot be paid again
And the confirmation is kept per country and per tab like the rest of the wizard data (AC-023): it does not appear in the other country's wizard and it is gone in a new tab.

**Verification:** Unit test of the wizard data store; end-to-end test for Colombia (reload on the confirmation; browser back to the plan step and forward again) and for the per-country separation.
