# AC-069: Identity document number always masked

Requirement: REQ-014.

Given the country's form fields in Strapi
Then the content model identifies which field holds the policyholder's identity document number through a fixed field kind, "identity document number", that names what the field holds, in the same way the pricing inputs are identified (AC-044); the kind is not a masking option, and masking has no setting of its own
And each country has exactly one field of that kind, and it is a text field (the field type stays one of the types of CAP-001)
And a country with no field of that kind, with two or more, or with the kind on a field that is not text, has invalid content (AC-017).

Given the identity document number field has a stored value
When the summary is shown
Then its value is always shown with every letter and digit replaced by the mask character `•`, except the last four letters or digits, which stay visible as entered
And every other character (dots, hyphens, spaces) is kept in its place as entered
And when the value has four letters and digits or fewer, all of them are replaced
And, for example: `1234567890` is shown as `••••••7890`; `123456` as `••3456`; `12.345.678-5` as `••.•••.678-5`; `12345678-k` as `•••••678-k`; `1234567-K` as `••••567-K`
And the complete value does not appear anywhere on the summary step or on the confirmation, including text exposed only to assistive technologies
And the stored value stays complete, so editing the step shows it in full (AC-071)
And the document type (seed: "Tipo de documento" in Colombia) and every other field are shown unmasked as in AC-068.

The rule and the field kind are the same for every country and fixed in code; no code names a field, a document type or a country to decide what is masked.

**Verification:** Unit test of the masking function (the examples above, values of four or fewer letters and digits, separators at the start and the end); unit test of the shared content schemas with no identity document number field, with two, and with the kind on a field that is not text, for fixtures of both countries; end-to-end test for Colombia (document number) and Chile (RUT) checking the masked text and that the complete value is absent from the page.
