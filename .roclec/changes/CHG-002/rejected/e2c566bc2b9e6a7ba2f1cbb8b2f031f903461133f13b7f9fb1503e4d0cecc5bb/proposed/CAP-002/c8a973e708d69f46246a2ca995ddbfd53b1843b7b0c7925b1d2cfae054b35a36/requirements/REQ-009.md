# REQ-009: Prices and the simulated final price

Prices are whole amounts in the country's currency and are formatted with the currency code and formatting locale of the country's entry in Strapi (ADR-001). The final price of the chosen plan is obtained from the stateless price-quote endpoint, which applies the simulated rule documented in this capability to the plan's published base price and to the policyholder's and the vehicle's ages derived from the step 1 data. Only those ages, the plan and the country leave the browser for this purpose; no entered value is sent, stored or logged (P5), and the browser uses no token (P4).

Acceptance: AC-042, AC-043, AC-044, AC-045, AC-046, AC-047, AC-066.
