# AC-048: Only one plan is chosen

Requirement: REQ-010.

Given the plan step shows the country's plans and none is chosen
When the person chooses a plan
Then that plan is marked as chosen: it shows the text configured for the chosen plan and a visual mark that does not rely on color alone, and it is exposed as selected to assistive technologies
And it is stored at once as the chosen plan in the country's wizard data
When the person then chooses another plan
Then the new plan is marked and stored as chosen, the previous plan is no longer marked and no longer shows a final price
And at no time is more than one plan marked as chosen.

**Verification:** Unit test (component) with fixtures for both countries; end-to-end test for Colombia and Chile choosing one plan and then another.
