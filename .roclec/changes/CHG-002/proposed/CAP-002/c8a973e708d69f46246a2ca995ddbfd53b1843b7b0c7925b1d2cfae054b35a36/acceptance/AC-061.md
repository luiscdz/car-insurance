# AC-061: Keyboard-only use of the plan list

Requirement: REQ-012.

Given the plan step of each country
When the person uses only the keyboard
Then they can reach every plan, choose a plan, change the choice, activate retry after a price error, go back and continue, in a logical order that follows the visual order
And focus is always visible and never hidden, and there is no keyboard trap.
