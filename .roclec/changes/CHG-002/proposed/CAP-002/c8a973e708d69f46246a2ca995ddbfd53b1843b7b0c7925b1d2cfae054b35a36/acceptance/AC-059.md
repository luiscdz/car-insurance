# AC-059: Plans loading, unavailable or invalid

Requirement: REQ-011.

Given the person opens any address of a country's wizard
Then the country's published, active plans are requested, filtered by the country, together with the country and its steps
And while any of these requests has not arrived, the loading state of AC-015 is shown
When the plans request fails (network failure or HTTP error status)
Then the unavailable state of AC-016 is shown, and its retry action requests the plans again together with the rest of the content, keeping the data already stored for the country in this tab
When the plans received are not valid (AC-041)
Then the invalid state of AC-017 is shown
And in none of these states is any step of the wizard, any plan or any partial plan list shown.

**Verification:** Unit test (component) of the three states; end-to-end test with the plans request blocked from the browser.
