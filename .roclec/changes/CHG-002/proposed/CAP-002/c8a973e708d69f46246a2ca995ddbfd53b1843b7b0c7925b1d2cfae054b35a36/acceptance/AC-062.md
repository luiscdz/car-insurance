# AC-062: Responsive plan list and target size

Requirement: REQ-012.

Given the plan step of each country with its seeded plans
When it is shown at 1280 CSS pixels wide
Then the plan cards are shown side by side, continuing on a new row when they do not fit
When it is shown at 375 CSS pixels wide
Then the plan cards are stacked in one column in display order
And at 320, 375 and 1280 CSS pixels all content is visible without horizontal scrolling, with and without a chosen plan and messages shown
And every interactive target is at least 24 × 24 CSS pixels.

**Verification:** End-to-end test (no horizontal overflow at 320 and 375 px; cards in one column at 375 px and in one row at 1280 px; target sizes) for both countries, and declared manual check at 375 and 1280 px.
