# AC-036: Only the country's published, active plans, in configured order

Requirement: REQ-008.

Given Colombia and Chile have plans in Strapi, some published and active, some published but not active, and some saved only as drafts
When the person who completed the form steps reaches the plan step at `/co`
Then exactly the plans of Colombia that are both published and active are shown, in ascending configured order
And no plan of Chile, no inactive plan and no draft plan is shown
And the same holds for `/cl` with Chile's plans.

Plans with the same order value are shown in a stable order across loads: ascending creation order in Strapi (as AC-004).

**Verification:** End-to-end test for Colombia and Chile with the seed data, plus an inactive plan and a draft plan created for each country by the test setup with a test-only credential that never reaches the browser; unit test with fixtures for both countries, including equal order values.
