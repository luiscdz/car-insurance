# AC-038: Recommended plan

Requirement: REQ-008.

Given exactly one of the shown plans is marked as recommended in Strapi
When the plan list is shown
Then that plan shows the recommended badge text from Strapi and the recommended styling of the design reference (primary border and info surface)
And the badge text is part of what assistive technologies announce for that plan
And no other plan shows the badge or the styling.

Given none of the shown plans is marked as recommended
Then no plan is distinguished.

Given more than one of the shown plans is marked as recommended
Then only the first of them in display order is distinguished, and the others are shown as plans that are not recommended.

Being recommended changes neither the order of the plans nor the choice: no plan is chosen in advance.

**Verification:** Unit test (component) with zero, one and two recommended plans, fixtures for both countries; end-to-end test with the seeded recommended plan of each country.
