# AC-066: Public access for plans and the price quote

Requirement: REQ-009.

Given a fresh start of the project, or any later start
Then the public role of Strapi has exactly the read actions (`find`, `findOne`) of the content types the wizard reads, now including plans, plus the price-quote endpoint, and nothing else
And the browser reads plans and requests the final price without any token (P4).

The simulated payment endpoint is not part of this change.

**Verification:** Unit test of the public role bootstrap (the exact list of public actions, applied idempotently); end-to-end test observing that the plan and price-quote requests carry no authorization header.
