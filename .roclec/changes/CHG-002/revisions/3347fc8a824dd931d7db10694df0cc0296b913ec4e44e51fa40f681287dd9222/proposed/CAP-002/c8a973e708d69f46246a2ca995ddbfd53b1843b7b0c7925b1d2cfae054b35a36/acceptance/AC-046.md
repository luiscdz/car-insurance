# AC-046: Only derived ages leave the browser

Requirement: REQ-009.

Given the person entered their data in the form steps
When the final price is requested
Then the request carries only the country code, the plan's identifier, and the policyholder's age and the vehicle's age when available (AC-044)
And no value entered in a form step, such as the document number, the RUT, the birth date, the license plate, the make or the vehicle year, appears in that request, in any other request sent to Strapi, in the address or in the browser console
And the price-quote endpoint stores nothing (no quote, no inputs, no personal data) and does not log the inputs it receives.

This criterion keeps AC-026 true while the person is on the plan step.

**Verification:** End-to-end test observing the requests, the address and the console on the plan step, for Colombia and Chile; unit test of the price-quote endpoint showing that it writes nothing and logs no input.
