# AC-047: Final price cannot be obtained

Requirement: REQ-009.

Given the person chose a plan
When the final price request fails (network failure or HTTP error status) or its answer is not a whole amount greater than zero
Then the chosen plan shows the price error message from Strapi with its retry action, announced to assistive technologies, and no final price and no technical detail
And the plan stays chosen, and continue does not advance (AC-051)
When the person activates retry
Then the final price is requested again, with the waiting state of AC-045, and is shown if it now arrives.

Choosing another plan replaces the error with the request for the new plan (AC-049).

**Verification:** Unit test (component) of the error and retry; end-to-end test for one country with the price-quote request blocked from the browser, then allowed before retry.
