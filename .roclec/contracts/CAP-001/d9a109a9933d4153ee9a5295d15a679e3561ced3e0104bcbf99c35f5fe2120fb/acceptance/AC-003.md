# AC-003: Country theme with fallback

Requirement: REQ-001.

Given a country whose entry in Strapi has a valid theme (primary color and accent color as valid color values, and a logo)
When any screen of that country's wizard is shown
Then the elements the design reference assigns to the primary and accent tokens use the country's colors, and the country's logo is shown
When the theme is missing or any of its values is malformed
Then the default theme of the design reference is used and the text placeholder replaces the logo, and the wizard still works.

Layout, components and typography are the same for both countries.

**Verification:** Unit test (valid, missing and malformed theme, fixtures for both countries) and declared manual check of the seeded themes of Colombia and Chile at both reference widths.
