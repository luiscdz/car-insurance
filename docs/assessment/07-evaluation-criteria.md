# Evaluation Criteria

**65%** of the score covers the agentic flow and its artifacts; **35%** covers the application.

| Criterion | What we look at | Weight |
|-----------|-----------------|--------|
| Agentic flow design | Clear responsibilities per subagent, defined inputs and outputs, skills with real value, a context file that governs generation | 20% |
| Human in the loop and control | Justified checkpoints, approval or rejection criteria, evidence that the person corrected the agent | 15% |
| Specs and ADRs | Specs that detect gaps in the user story and make it verifiable; ADRs with real alternatives and consequences | 15% |
| Review and verification | Real findings in reviews, traceable fixes, tests that validate behavior | 15% |
| Multi-country strategy and configurability | Content differentiated by country without duplicating the app; form and plans 100% configurable from Strapi | 15% |
| Angular and Strapi technical quality | Modern Angular, typing, loading and error state handling, token and permission security | 10% |
| Communication | Clarity of `FLOW.md` and README | 10% |
