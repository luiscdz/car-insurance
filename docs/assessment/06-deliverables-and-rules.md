# Deliverables and Rules

Deliver a Git repository, public or private and shared with whoever sent you the test.

## Deliverables checklist

The repository must contain:

- [ ] The Angular application code and the Strapi project, with seed data for Colombia and Chile.
- [ ] `README.md` with instructions to run the project and any requirements not met.
- [ ] `FLOW.md` with the step by step of the agentic flow and its diagram.
- [ ] A global context file (`AGENTS.md`, `CLAUDE.md` or equivalent).
- [ ] Versioned subagent and skill definitions.
- [ ] A specs folder, at least one spec per user story.
- [ ] An ADRs folder, with at least the multi-country strategy ADR.
- [ ] Evidence of code reviews (reports, PR comments or similar) and how they were resolved.
- [ ] Unedited logs or exports of your sessions with the agents.

## Rules

- Use fictitious data only. Do not include real personal data or credentials in the repository.
- If a tool requires a paid plan and you don't have access, use a free alternative and say so.
